Hello! My name is Luiz Gustavo and I'm 20 years old. I'm a Back-End Java Developer with experience in the Spring ecosystem. I've worked on projects involving system development, security implementation, and efficient data management.

I also have experience with MySQL and PostgreSQL databases.

I'm currently looking for an opportunity as a Junior Java Developer or Intern where I can keep learning and contributing with my knowledge.

I currently work at Up Estágio 🚀, where my main responsibility is automating processes, especially those focused on candidate selection. I use Google Sheets with JavaScript and low-code tools to simplify and speed up data management and daily tasks.
