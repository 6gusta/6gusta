### 🚀 Sobre Mí
¡Hola! Me llamo Luiz Gustavo y tengo 20 años. Soy Desarrollador Back-End Java con experiencia en el ecosistema Spring. He trabajado en proyectos que involucran desarrollo de sistemas, implementación de seguridad y gestión eficiente de datos.

También tengo experiencia con bases de datos MySQL y PostgreSQL.

Estoy buscando una oportunidad como Desarrollador Java Junior o Pasante, donde pueda seguir aprendiendo y aportando con mis conocimientos.

### 💼 Dónde Trabajo Actualmente
Actualmente trabajo en Up Estágio 🚀, donde mi función principal es automatizar procesos, especialmente enfocados en la selección de candidatos. Utilizo Google Sheets con JavaScript y herramientas low-code para facilitar la gestión de datos y agilizar tareas del día a día.

Además, creo chatbots y agentes de IA con plataformas como N8N y Typebot. Estos agentes ayudan a automatizar la atención al cliente y mejorar la comunicación. También participo en la creación de sistemas como RAG para la lectura de información y un CRM para gestionar todo de manera más eficiente.
